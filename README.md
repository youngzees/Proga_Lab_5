ВЫВОД

В ходе лабораторной работы были разработаны четыре многофайловых проекта на C++ с использованием контейнеров STL и range-based for. Реализованы программы для учёта товаров на складе (4D-контейнер, адресация AXXXX), электронной очереди с жадным распределением посетителей по окнам, маршрутов троллейбусов (map и enum class) и учёта студентов с комбинацией vector и set. Освоены принципы разделения кода на заголовочные и исполнительные файлы, обработка пользовательских команд и работа с контейнерами. Все программы протестированы и работают корректно.
